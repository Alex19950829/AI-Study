# 🤖 AI 从入门到精通 · 交互式全景课程 PPT & 工程指南

> 本项目将大模型底层原理、Prompt 提示词工程、Agent 智能体架构、RAG 知识库切片实操、LoRA 微调物理拆解与本地显存计算，系统性提炼并封装为一份**包含 27 页精美卡片与丰富交互组件的 HTML 全景 PPT 项目** (`ai_course_ppt.html`)。

---

## ✨ 核心亮点与特色

- 🎨 **现代 UI 设计 & 主题切换**：基于 Apple / GitHub 原生质感设计，支持浅色 / 深色（Dark Mode）一键无缝切换。
- 🧮 **全交互式实操工具箱（无需后端，纯前端闭环）**：
  - **提示词废话费用放大器**：动态拖拽提示词字数与日调用量，精算一年白白浪费的资金。
  - **P-A-O 智能体控制循环演练**：分步模拟 Agent 规划（Plan）➔ 行动（Act）➔ 观察（Observe）自愈闭环。
  - **豆包 / DeepSeek 深度思考演示**：对比秒答（System 1）与思考草稿（System 2）的划掉重推避坑逻辑。
  - **1:1 动态显存计算器**：支持 NVIDIA 独显（RTX 4090 / 5090D）与 Apple Silicon 统一内存（75% 可用上限打折换算），实时精算 INT4 / INT8 / FP16 显存硬开销与匹配度。
  - **开源三件套检查器与满血/蒸馏版对比动画**：动态呈现“开放权重”真相与算力差异。
- ⌨️ **极佳的演示操纵体验**：支持键盘左右方向键 `←` / `→` 翻页、`M` 键一键唤出全局 27 页大图目录。
